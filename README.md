Мощный инструмент для конвертации музыкальных файлов формата `.chordpro` в красивые изображения (JPG) и HTML-страницы. Поддерживает различные макеты, транспонирование, германскую нотацию и сложные музыкальные сетки (Grids).

## 🚀 Установка

### 1. Подготовка окружения
Рекомендуется использовать виртуальное окружение Python:

```bash
python3 -m venv venv
source venv/bin/activate  # macOS/Linux
# venv\Scripts\activate   # Windows
```

### 2. Установка зависимостей
Установите необходимые пакеты из файла требований:

```bash
pip install -r requirements.txt
```

### 3. Установка браузеров для Playwright
Конвертер использует движок браузера для рендеринга изображений:

```bash
playwright install
# Если команда не найдена:
# python -m playwright install
```

## 🛠 Использование

### 1. Режим из папки (как раньше)

- Поместите ваши файлы `.chordpro`, `.pro` или `.cho` в папку `input_cho/` (см. константу `INPUT_DIR` в `chordpro_to_jpg.py`).
- Запустите скрипт без дополнительных флагов:

```bash
python chordpro_to_jpg.py
```

- Результаты (HTML и JPG) появятся в папке `output_jpg/` (константа `OUTPUT_DIR`).

Этот режим удобен для локального тестирования и ручной правки отдельных файлов.

### 2. Режим из базы данных (флаг `-db/--from-db`)

Скрипт умеет брать тексты песен в формате ChordPro прямо из таблицы `songs` (`songs.chordpro`) проекта `Samara_sbornik_bot` и рендерить их в JPG.

#### 2.1 Требования к подключению к БД

- В корне проекта `Sbornik_samara_bot` должен существовать модуль `config_data.config` с функцией `load_config()` (как в основном боте).
- Файл окружения (`.env` или `.env.remote`) должен содержать переменные:
  - `DATABASE`
  - `DB_HOST`
  - `DB_USER`
  - `DB_PASSWORD`
- В текущем виртуальном окружении должны быть установлены:
  - `psycopg2`
  - `environs`

Именно через `load_config()` скрипт узнаёт параметры подключения к базе.

#### 2.2 Вызов по номерам песен

В самом простом случае вы можете передать один или несколько номеров песен:

```bash
# Одна песня
python chordpro_to_jpg.py -db 321

# Несколько песен
python chordpro_to_jpg.py -db 321 378 512
```

Для каждой указанной песни:

- из БД читается `songs.chordpro` и заголовок (из `name` / `alt_name`);
- текст парсится как ChordPro и рендерится так же, как файл из папки;
- имя выходного файла формируется как `<num> <title>.jpg` и сохраняется в `output_jpg_test/`.

#### 2.3 Диапазоны номеров

Флаг `-db/--from-db` поддерживает диапазоны номеров в формате `N-M`:

```bash
# Все песни с 300 по 400 включительно
python chordpro_to_jpg.py -db 300-400

# Комбинация диапазонов и одиночных номеров
python chordpro_to_jpg.py -db 300-305 320 330-335
```

- Диапазон `300-305` разворачивается в номера `300, 301, 302, 303, 304, 305`.
- Если указать `400-390`, границы будут автоматически упорядочены и будет использован диапазон `390-400`.
- Некорректные токены (`abc`, `10-`, `-20` и т.п.) пропускаются с предупреждением, остальная часть списка обрабатывается.

## ⚙️ Параметры командной строки (CLI)

Вы можете управлять поведением конвертера с помощью флагов:

| Флаг | Полное имя | Описание | Пример |
|------|------------|----------|--------|
| `-t` | `--transpose` | Транспонирование аккордов на указанное количество полутонов. | `python chordpro_to_jpg.py -t 2` (поднять на 1 тон) |
| `-capo` | `--capo` | Установить `capo` в метаданных и автоматически компенсировать тональность вниз на то же число полутонов. | `python chordpro_to_jpg.py -capo 2` |
| `-g` | `--ger` | Германская нотация на входе. См. раздел [Нотация](#-нотация-b-vs-h). | `python chordpro_to_jpg.py --ger` |
| `-s` | `--std` | Стандартная нотация на выходе. См. раздел [Нотация](#-нотация-b-vs-h). | `python chordpro_to_jpg.py --std` |
| `-l` | `--layout` | Выбор макета страницы. Варианты: `standard` или `sidebar`(по умолчанию). | `python chordpro_to_jpg.py -l standard` |
| `-index` | `--index` | Включить режим подстрочных индексов для дополнений аккордов (dim7, maj7, sus4, 7, 9 и т.п.), кроме `#/b` и минорного `m` сразу после тоники. Работает и для слэш-аккордов: индекс применяется только к «голове» (до `/`), бас после `/` остаётся обычным. | `python chordpro_to_jpg.py -index` |
| `-ex` | `--expand-chorus` | Разворачивать ссылки на секции (заменять комментарии с названием припева, пре-припева или бриджа на их текст). | `python chordpro_to_jpg.py -ex` |
| `-db` | `--from-db` | Брать песни из БД по номерам и/или диапазонам вместо чтения файлов из папки. | `python chordpro_to_jpg.py -db 300-320 400` |

---

### `-t` и `-capo`: разница в знаках

- `-t/--transpose` работает в обе стороны: можно передавать `+N` и `-N`.
- `-capo/--capo` всегда трактуется как компенсация вниз:
  - `-capo 2`, `-capo +2` и `-capo -2` дают одинаковый результат.
- Если у песни уже есть `{capo: ...}` в исходном ChordPro и передан `-capo`, значение из CLI заменяет исходное.
- При `-capo` эталонное звучание берётся из исходной пары `{key}` + `{capo}`:
  - меняется «тональность аккордов» (что в скобках), а фактическая тональность звучания сохраняется;
  - при этом `-t` дополнительно сдвигает уже эталонную тональность.

## 🎵 Особенности и Синтаксис

### 🎼 Нотация (B vs H)
Конвертер поддерживает как стандартную, так и германскую музыкальную систему, популярную в СНГ.

*   **По умолчанию (без флагов):**
    *   Вход: Стандартная нотация — `B` = Си, `Bb` = Си бемоль.
    *   Выход: Германская нотация — `H` = Си, `B` = Си бемоль.
*   **С флагом `--ger` (German):**
    *   Вход: Германская нотация — `H` = Си, `B` = Си бемоль.
    *   Выход: Германская нотация — `H` = Си, `B` = Си бемоль.
*   **С флагом `--std` (Standard):**
    *   Вход: Стандартная нотация — `B` = Си, `Bb` = Си бемоль (по умолчанию).
    *   Выход: Стандартная нотация — `B` = Си, `Bb` = Си бемоль.
*   **Комбинация флагов `--ger --std`:**
    *   Вход: Германская нотация — `H` = Си, `B` = Си бемоль.
    *   Выход: Стандартная нотация — `B` = Си, `Bb` = Си бемоль.

### 🔡 Форматирование аккордов и подстрочные индексы (`-index`)

При включённом флаге `-index` длинные дополнения к аккордам выводятся уменьшенным шрифтом как подстрочный индекс, чтобы уменьшить разрывы текста и сделать строки компактнее.

- **Что считается основой аккорда:**
  - Буква тоники `A–G`, `H` или `B`.
  - При наличии — знак диеза/бемоля `#` или `b` сразу после тоники.
  - Минорное `m`, если оно идёт сразу после тоники/`#/b` и **далее либо цифры, либо конец строки**.
- **Всё, что идёт после основы, становится индексом**:
  - `F#m` → основа `F#m`, индекс пусто (весь аккорд обычным шрифтом).
  - `F#m7` → основа `F#m`, индекс `7`.
  - `F#dim7` → основа `F#`, индекс `dim7`.
  - `Cmaj7` → основа `C`, индекс `maj7`.
  - `Esus4` → основа `E`, индекс `sus4`.
- **Слэш-аккорды (бас через `/`)**:
  - Индекс всегда относится только к «голове» (части до `/`), а бас после `/` выводится обычным шрифтом.
  - `Esus4/G#` → показывается как `E` + подстрочный `sus4` + `/G#`.
  - `F#m7/G#` → `F#m` + подстрочный `7` + `/G#`.
  - `Cmaj7/B` → `C` + подстрочный `maj7` + `/B`.

Без флага `-index` аккорды выводятся как одна строка целиком, без подстрочных индексов.

### 📄 Секции и Цвета
Скрипт распознает стандартные директивы ChordPro и окрашивает их в разные цвета для удобства чтения:

1.  **Куплет (Verse)**
    *   Директива: `{sov}` или `{start_of_verse}` (или просто текст без директив).
    *   *Стиль:* Белый фон, без рамки.

2.  **Припев (Chorus)**
    *   Директива: `{soc}` или `{start_of_chorus}`.
    *   *Стиль:* Светло-серый фон, **синяя** левая граница.

3.  **Бридж (Bridge)**
    *   Директива: `{sob}` или `{start_of_bridge}`.
    *   *Стиль:* Светло-оранжевый фон, **оранжевая** левая граница.

4.  **Инструментал / Сетка (Grid)**
    *   Директива: `{sog}` или `{start_of_grid}`.
    *   *Стиль:* Светло-бирюзовый фон, **бирюзовая** левая граница, моноширинный шрифт.

5.  **Тег (Tag)**
    *   Активируется, если назвать секцию "Tag:": `{sov: Tag:}`.
    *   *Стиль:* Розоватый фон, **розовая** левая граница.

### 🎹 Инструментальная сетка (Grid)
Специальный режим для записи тактов. Используется внутри `{sog} ... {eog}`.

**Синтаксис:**
*   **Тактовые черты:** Используйте `|`, `||`, `|:`, `:|` для разделения тактов.
*   **Аккорды:** Пишутся как обычно (можно без квадратных скобок внутри сетки).
*   **Вольты:** Числа в начале такта (например, `1.`, `2.`) автоматически отображаются как надстрочные индексы (вольты) над тактовой чертой.
*   **Спецсимволы:**
    *   `.` (точка) — добавляет отступ (пробел).
    *   `/` — слэш.
    *   `%` — знак повтора такта.

**Пример:**
```text
{sog: Intro}
|: G | C | D | G :|
| 1. Em | D |
| 2. C | D | G ||
{eog}
```

### 🔄 Повторы припевов (Chorus Reference)
Если у вас есть повторяющийся припев, не обязательно копировать его текст.
1. Опишите припев один раз: `{soc: Припев} ... {eoc}`.
2. В нужном месте вставьте комментарий с названием припева: `{c: Припев}` или `{comment: Припев}`.
3. Скрипт автоматически подставит содержимое припева на место комментария.

### 📐 Макеты (Layouts)

#### 1. Standard (`-l standard`)
Классическое расположение: блоки идут друг за другом вертикально. Название секции (например, "КУПЛЕТ 1") пишется над блоком.

#### 2. Sidebar (По умолчанию)
Компактный вид. Названия секций выносятся в левую колонку, контент — справа.
*   **Умное выравнивание:** Если первая строка секции содержит аккорды, метка секции опускается чуть ниже, чтобы выровняться по строке текста (лирике), а не по аккордам.

### ✨ Визуальное выравнивание
Скрипт автоматически центрирует аккорды над соответствующим слогом текста для красоты.
*   Если аккорд длиннее слога, текст раздвигается.
*   Если аккорд в начале строки, добавляются пробелы.
*   Отключить можно флагом `--no-align`.
