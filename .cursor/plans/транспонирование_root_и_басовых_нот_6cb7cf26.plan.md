# Переделка транспонирования аккордов

## Проблема

Текущая реализация пытается распознать весь аккорд внутри квадратных скобок через `pychord.Chord()`. Если аккорд содержит дополнительные символы (например, `[Eыжфдаоыфв54л/G5d546]`) или специфические обозначения, pychord не может его распознать и аккорд не транспонируется.

## Решение

Вычленять только root ноту (сразу после `[`) и басовую ноту (после `/`), транспонировать их через `pychord.transpose_note()`, и соединять обратно с остальными символами.

## Изменения в [chordpro_parser.py](chordpro_parser.py)

### 1. Добавить вспомогательные функции для работы с нотами

- `extract_root_note(chord_str)` - извлекает root ноту (заглавная буква + опционально # или b) сразу после начала строки
- `extract_bass_note(chord_str)` - извлекает басовую ноту (заглавная буква + опционально # или b) после `/`
- `transpose_chord_parts(chord_str, semitones, new_key, rbc_mode)` - основная функция транспонирования:
- Извлекает root ноту
- Извлекает басовую ноту (если есть)
- Нормализует ноты для pychord (H->B, B->Bb для немецкой нотации)
- Транспонирует через `transpose_note()`
- Форматирует обратно в немецкую нотацию
- Соединяет транспонированные ноты с остальными символами

### 2. Обновить метод `transpose()`

Заменить логику в строках 180-208 и 214-225:

- Вместо `Chord(english_chord_str)` использовать `transpose_chord_parts()`
- Если root нота не найдена, пропускать транспонирование (оставлять аккорд как есть)

### 3. Правила обработки

- Root нота: паттерн `^[A-GH][#b]?` в начале строки аккорда
- Басовая нота: паттерн `/[A-GH][#b]?` после слэша
- Ноты всегда заглавные (A-G, H для немецкой нотации)
- Сохранять все остальные символы на своих местах
- Обрабатывать конвертацию H↔B для немецкой нотации

## Примеры

- `[Eыжфдаоыфв54л/G5d546]` → транспонировать E и G, сохранить остальное → `[Fыжфдаоыфв54л/G#5d546]` (при +1 полутон)
- `[Esus4]` → транспонировать E → `[Fsus4]`
- `[H/D#]` → транспонировать H→B и D# → `[C/E]` (при +1, с конвертацией обратно в H/E)
- `[*]` или `[N.C.]` → пропустить (root нота не найдена)
